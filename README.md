# 🖥️ EXPERIMENT 1 – Installation of VirtualBox and Creation of Virtual Machines

## 🎯 Objective

Install **Oracle VM VirtualBox** and create a virtual machine running **Ubuntu Linux**.

## 📝 Description

This experiment demonstrates the installation of Oracle VM VirtualBox on a Windows host machine and the creation of an Ubuntu virtual machine using an ISO image. The VM is configured with appropriate memory, virtual hard disk, and storage settings before installing Ubuntu.

### 🛠️ Software Used

- Oracle VM VirtualBox
- Ubuntu Desktop ISO
- Windows 10

### ✅ Outcome

Successfully installed Oracle VM VirtualBox and created a bootable Ubuntu virtual machine.

# 🗄️ EXPERIMENT 5 – Cloud Object Storage Manager Using Python & MinIO

## 🎯 Objective

Develop a Python application that interacts with a local **MinIO Server** to perform cloud object storage operations.

## 📝 Description

A local MinIO server was installed and configured.

Using the **MinIO Python SDK**, a Python application was developed to perform cloud object storage operations including:

- 📁 Bucket Creation
- ⬆️ Object Upload
- ⬇️ Object Download
- 📋 Listing Bucket Contents
- 🗑️ Object Deletion

The application demonstrates the working of an **S3-compatible Object Storage Service**.

### 🛠️ Software Used

- Python 3
- MinIO Server
- MinIO Python SDK
- Ubuntu Linux

### ✅ Outcome

Successfully implemented cloud object storage operations using the MinIO Python SDK and local MinIO server.
